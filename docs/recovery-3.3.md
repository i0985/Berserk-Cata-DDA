# Восстановление 3.3-apostol

## Исходный снимок

- Источник: `Berserk-3.3-apostol-math-load-fix.zip`, предоставлен владельцем проекта 2026-10-20.
- SHA-256 архива: `320e5223f0c94cb05d33e98d752e4eaf7b584e0c1c92ddf535e46e9dc8efbb6f`.
- 403 файла в двух пакетах: `mods/Berserk` и `mods/Berserk_chibi_tileset`.
- Первоначальный коммит восстановления сохраняет байты всех файлов архива без изменений.
- Служебные скрипты и проверки унаследованы от 3.2; они НЕ являются восстановленными генераторами 3.3. Не запускать старые генераторы поверх данных 3.3 без отдельного анализа.
- Старые локальные коммиты `97c769a` и `baf2b05` отсутствуют на сервере; последующие исправления восстанавливаются отдельными новыми коммитами, а не выдаются за прежнюю историю.

## Порядок сохранения

1. Локальная папка используется только для редактирования и проверок.
2. Каждый законченный пакет коммитится и отправляется в `3.3-apostol-test`.
3. После отправки сверяются локальный SHA и удалённая ссылка GitHub.
4. В отчёте о завершении указываются ветка, коммит и результат проверок.
5. При недоступности отправки работа не объявляется сохранённой на GitHub.
6. Новые литературные сценарии диалогов октября не включаются в этот этап.

## Проверки исходного снимка

- Проверка assets: успешно, 352 JSON, 2 пакета, 4 каталога переводов.
- Унаследованный полный набор 3.2: 322 теста, 95 failures и 69 errors на исходном архиве до исправлений. Среди причин — изменённые состояния/планировки и неполные старые интерпретаторы EOC. Это не считается успешной проверкой 3.3.
- Старые тесты не удаляются и их красный результат не скрывается. Для восстановленных правил добавляются/адаптируются отдельные актуальные проверки.
- Нативная загрузка, анимация, AI, распространение огня и игровой баланс требуют игрового прогона в целевой CDDA; проверки Python его не заменяют.

## Результат восстановления

- `b6d0c2f`: точный снимок 403 файлов архива, проверенный по байтам.
- `add3397`: способности всех направлений, прямой урон Конрада, мгновенные договоры, ночной бюджет, спрайт раннего меча и короткие сообщения.
- `f828466`: запрет новой выдачи уникальных мечей и брони с момента принятия силы, совместимость старых форм, возврат поставок; помощь Рикерта и продолжение Флоры не закрываются этим запретом.
- Следующий коммит: расширение проекций до 10, RU/ZH переводы, согласование проверок и этот отчёт. Окончательный SHA берётся из истории удалённой ветки.

Лабораторные проекции: Зодд, Гриффит/Фемто, Войд, Граф, Уайлд, Розина, Грюнбельд, Слан, Убик и Конрад. Новые семь не наследуют оригиналов: у них нет сюжетных флагов смерти, договоров, плоти и реликвий оригинала. Убийство вызывает только существующую проверку доступности Бехелита. Сумма весов проекций в модовом дополнении GROUP_NETHER остаётся 16 при общей сумме 186; это не процент лабораторий и не итоговая вероятность объединённой ванильной группы.

### Проверки итоговых данных

- Успешно: assets — 355 JSON, 2 пакета, 27 определений тайлсетов, 29 листов спрайтов, 74 ID тайлов, 4 каталога переводов.
- Успешно: 43 целевые проверки (`test_recovery_33`, `test_apostol_projections_33`, `test_night_hunt_budget`, `test_boss_balance`, `test_arm_cannon_install`, `test_package_release`). Из них 33 проверяют восстановленные правила превращений, наград, ночи и проекций.
- Успешно: сборка трёх установочных ZIP; повторное применение скриптов восстановления не должно менять данные.
- Проверено: повторяющихся верхнеуровневых EOC нет; удалённых колокольчиков в mapgen нет. Совместимые определения/очистка старых посещённых карт сохранены; подземная пещера остаётся исключением.
- Полный унаследованный набор: 348 тестов, 96 failures и 68 errors. Множество 164 неуспешных отчётов совпадает с исходным снимком; новых неуспешных сценариев не появилось. Неполные интерпретаторы и старые ожидания 3.2 остаются отдельной работой, результаты не объявляются зелёными.
- Числа силы восстановлены по согласованному назначению, а не извлечены из отсутствующих старых коммитов. Сравнение с игровым балансом — задача плейтеста.

### Что намеренно не заявляется исправленным

- Строгое размещение нового пепельного прорыва в кольце 12–24 OMT: известная нерешённая географическая задача. Увеличение предела поиска не выдаётся за её решение.
- Новые большие литературные деревья Годо, Рикерта, Рыцаря, Флоры, пленника, апостолов и Руки Бога: подготовлены в переписке, но пока не внедрены. Точечные строки о закрытом заказе нужны существующим механическим ограничениям.
- Нативный запуск целевой экспериментальной CDDA и игровой бой здесь не проверялись.

### Как воспроизвести восстановление

На уже сохранённом исходном снимке, по порядку:

```sh
python3 tools/recover_apostol_33.py
python3 tools/recover_human_equipment_33.py
python3 tools/recover_apostol_projections_33.py
python3 tools/recovery_33_translations.py
python3 tools/validate_mod_assets.py
python3 tools/package_release.py
```

Новые JSON в `mods/` остаются основным редактируемым результатом. Эти узкие скрипты повторяют только восстановленные пакеты; старые генераторы 3.2 запускать поверх них нельзя.
