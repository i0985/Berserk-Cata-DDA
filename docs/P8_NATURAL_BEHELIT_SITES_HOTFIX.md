# Исправление естественного появления мест Бехелита

4 октября 2026 · `3.0.0-dev` · ветка `codex/3.0-new-horizon`.
Продолжение общей сборки G. Все накопленные A–G изменения сохранены.

## Подтверждённая причина в данных и исходниках

У дуба, пещеры, часовни и экспедиции одновременно были
`occurrences: [0, 1]` и `OVERMAP_UNIQUE`. В CDDA 0.I-1 поле occurrences для
обычного special означает минимум/максимум размещений, но для unique special
оно используется как вероятность допуска. В `src/overmap.cpp`,
`overmap::place_specials`, вызов `x_in_y` с нулевым числителем исключает эти
четыре места из естественной генерации. Отладочное размещение обходило эту
предварительную стадию, поэтому ручное появление работало.

Это не зависимость от Затмения и не необходимость получить миссию.
Зарегистрированные specials автоматически попадают в стандартный набор
генерации через `overmap_specials::get_default_batch`; отдельный список региона
для включения этих четырёх объектов не требуется.

## Изменения

| Место | Special ID | Новый порядок |
|---|---|---|
| Проклятый дуб | `berserk_cursed_oak_special` | Обычный special, occurrences [1,1] |
| Пещера отголосков | `berserk_echo_cave_special` | Обычный special, occurrences [1,1] |
| Осквернённая часовня | `berserk_desecrated_chapel_special` | Обычный special, occurrences [1,1] |
| Пропавшая экспедиция | `berserk_lost_expedition_special` | Обычный special, occurrences [1,1] |

`OVERMAP_UNIQUE` удалён только у этих четырёх мест. Генератор запрашивает
одно место каждого вида в новом крупном overmap-регионе (180 × 180 OMT),
используя штатные попытки размещения. При отсутствии подходящего леса или
свободной композиции размещение может не состояться в конкретном регионе;
минимум позволяет движку искать соседний новый регион в его ограниченной зоне.
Это не по одному месту на каждой клетке глобальной карты и не рядом с героем.

Лесные ограничения сохранены. Для пещеры сохранены лесной вход, четыре
подземные клетки и условие `subterranean_empty`. Для часовни требуется место
под обе поверхностные клетки. Карты, лестницы, имена и все ID остались прежними.

Использованность тайника по-прежнему принадлежит самому месту через полное/
пустое состояние мебели. После состоявшегося Затмения общий обработчик не
выдаёт новый Бехелит. Эти условия не менялись; естественная генерация мест
сама не зависит от прохождения сюжета. Уникальные сюжетные охоты и Флора
сохраняют свои прежние правила.

## Отдельные ошибки приложенного лога

В `debug(20261004-182018).log` есть четыре `Unread data ... method` в
`mapgen/flora_siege_updates.json`: старые обновления assault west/east и
garden west/east содержали `method: json`. `load_update_mapgen` в 0.I-1 читает
`object`, но не поле method, которое применяется к другим веткам генерации.
Четыре поля удалены. ID обновлений, огонь, координаты и сроки осады сохранены.

Лог также показывает включённый `Berserk_chibi_tileset` при UltiCa
(`UltimateCataclysm`). Этот дополнительный мод предназначен для Chibi/MSX+/
Undead, поэтому его определения сообщают о несовместимости. Для UltiCa
нужен только основной `Berserk`; список совместимости дополнительного мода
не расширялся искусственно. Предупреждение о ещё отсутствующем cache-каталоге
само по себе не объясняет отсутствие мест.

## Старые миры и пользовательская приёмка

Уже построенные глобальные регионы не переразмещаются. Открытие новых локальных
тайлов внутри старого overmap тоже не запускает его генерацию заново. Для
обычного появления нужен новый мир или ещё не созданный крупный overmap-регион
старого мира. Старые отладочные места, предметы и сохранения не удаляются.

1. Установить обновлённый общий архив с полной заменой папок мода.
2. Для UltiCa оставить только основной мод. Проверить отсутствие четырёх
   ошибок `method` при загрузке.
3. Создать отдельный мир с обычными лесами и включённым Berserk. Дать игре
   сгенерировать глобальный регион; для осмотра можно раскрыть уже созданную
   глобальную карту отладкой, но не размещать сами specials вручную.
4. Искать поверхностные типы `berserk_cursed_oak`,
   `berserk_echo_cave_entrance`, `berserk_desecrated_chapel_nave` /
   `berserk_desecrated_chapel_reliquary`, `berserk_lost_expedition`.
5. Посетить найденные места: локальные карты должны соответствовать значкам,
   лестница пещеры должна вести в её подземную композицию.
6. В старом мире отдельно проверить появление при генерации нового крупного
   региона и сохранность прежде посещённых/отладочных мест.

В этой итерации выполнены чтение лога/исходников, правка данных и упаковка.
Тесты, валидаторы, симуляция генерации и бинарник CDDA не запускались.
Фактическое размещение в сборке игрока остаётся его плейтестом.
