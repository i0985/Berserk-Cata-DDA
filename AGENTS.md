# Работа с восстановленной 3.3

- Каноническая рабочая ветка этого восстановления: `3.3-apostol-test` в `i0985/Berserk-Cata-DDA`.
- `mods/Berserk` и `mods/Berserk_chibi_tileset` восстановлены из архива владельца. Старые генераторы 3.2 не являются источником данных 3.3: не запускать их поверх этих папок без проверки изменений.
- Сохранять каждый законченный пакет на GitHub. Локальный коммит без отправки не считать опубликованным или сохранённым удалённо.
- Если обычный `git push` недоступен, использовать подключение GitHub: создать blobs/tree/commit, обновить ветку без force с ожидаемым SHA, проверить удалённый SHA и совпадение дерева. Не менять существующие ветки пользователя.
- В отчёте всегда различать проверки данных, моделирование событий и настоящий игровой тест. Не объявлять старые проверки 3.2 актуальными для 3.3 без адаптации.
- Сценарии Годо и Рикерта из документов от 21 октября согласованы владельцем для переноса. Остальные новые сценарии октября остаются отдельным этапом. Позднее владелец разрешил ванильное доверие, восстановление кисти демоническим изменением и редкий протез: актуальный результат в `docs/apostol-body-trust-2026-10-21.md`.
- Для нового дерева Годо источник — `docs/dialogue_sources/godo-2026-10-21.json`, сборщик — `tools/build_godo_dialogue_33.py`. Старые `recover_*_33.py` восстанавливают архив и не должны запускаться поверх утверждённых новых диалогов. Сборщик ремонта сохраняет новый литературный текст.
- Для нового дерева Рикерта источник — `docs/dialogue_sources/rickert-2026-10-21.json`, сборщик — `tools/build_rickert_dialogue_33.py`. Общий файл диалогов кузни сохраняется. Пересборка: сначала Годо, затем Рикерт, затем `tools/build_apostol_body_rules_33.py`. Доверие — штатное `n_npc_trust()`, не счётчик заказов. Пожизненный отказ не снимается ростом доверия.
- Кисть восстанавливается один раз при первой фактической демонической мутации мода; отказные шрамы, наличие Бехелита и ванильные мутации не подходят. Не удалять установленную пушку, её боеприпас, Клеймо или глаз. Не подменять резерв пути ритуала готовой игровой цепочкой: ритуал ещё не реализован.
- Сохранять существующие ID, координаты, выданные награды и постоянные превращения. Не удалять уже полученное снаряжение.
