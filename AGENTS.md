- Сохранять каждый законченный пакет на GitHub. Локальный коммит без отправки не считать опубликованным или сохранённым удалённо.

- В отчёте всегда различать проверки данных, моделирование событий и настоящий игровой тест. Не объявлять старые проверки 3.2 актуальными для 3.3 без адаптации.
