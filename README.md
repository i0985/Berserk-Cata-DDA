# Berserk 3.4 — тестовая сборка

Фанатская кампания New Horizon для Cataclysm: Dark Days Ahead. Найдите Бехелит, переживите Затмение и решите, кем вернуться. В кампании есть кузня Годо и Рикерт, Рыцарь-Череп, дом Флоры, охоты на апостолов и пути превращения.

Ветка **`3.4`** отделена от [`3.3-apostol-test`](https://github.com/i0985/Berserk-Cata-DDA/tree/3.3-apostol-test). Рабочая версия игры — **CDDA 0.I-1**. Английский текст находится в данных мода, русский перевод поставляется с модом; китайский перевод неполный и использует английский для недостающих строк.

## Установка

1. Скопируйте `mods/Berserk` в пользовательскую папку `mods/` игры. В портативной сборке Windows она находится рядом с `cataclysm-tiles.exe`. Должен получиться путь `<CDDA>/mods/Berserk/modinfo.json`.
2. Для ChibiUltica, MSXotto+ и совместимых тайлсетов добавьте `mods/Berserk_chibi_tileset`. Включите этот графический мод вместе с основным. Для UltiCa графика уже входит в `Berserk`.
3. При обновлении замените целиком старые папки самого мода. Проверьте, что дубликаты не остались в `data/mods/`: игра может загрузить старую копию первой. Перезапустите игру.

Для проверки 3.4 используйте новый мир. Миграция старых журналов предусмотрена, но загрузка старых сохранений на этой ветке ещё не проверена в игре.

## Разработка

Данные в `mods/` — рабочий исходник. Меняйте нужные JSON и каталоги перевода напрямую. Старые конвейеры восстановления и сборки остались в истории ветки 3.3.

```sh
python tools/validate_mod_assets.py
python -m unittest discover -s tools -p 'test_*.py'
python tools/package_release.py
```

Архивы появятся в `dist/`. См. [что удалено и что сохранено](docs/cleanup-3.4.md), [переводы](mods/Berserk/lang/README.md) и [приёмку последнего плейтеста 3.3](docs/playtest-2026-11-02-followup.md). Проверки данных и сценариев не заменяют игровой тест.
